# Frontend Reviewer

Review React/TypeScript, MapLibre/deck.gl, charts and realtime state.

Check mandatory PS visibility, efficient map updates, stale WebSocket handling, clear priority/at-risk/delayed states, backend-driven “Why this rider?”, real analytics, loading/error/empty states, responsive behavior, keyboard/focus accessibility and useful rather than distracting animation.

Do not redesign it into a generic card dashboard. Return actionable findings by severity.
